# ERP Customer

**Orders, invoices and rates from the ERP, in your pocket.**

ERP Customer is the CRM app for customers of the ERP system: sign in to see orders and invoices,
check zone-based rate sheets, and browse the distribution centres. Built as a final-year major
project with Flutter and a Spring Boot API, deployed on Render with Supabase for the database and files.

This repository hosts the Android app downloads only.

## Download

**[Download the latest ERP Customer APK](https://github.com/GajendraNA/erp-customer-releases/releases/latest/download/erp-customer.apk)**

All versions: [Releases](https://github.com/GajendraNA/erp-customer-releases/releases)

No Android phone? Use the web version: **[erp-mob.vercel.app](https://erp-mob.vercel.app)**

## Install

1. Download `erp-customer.apk` on your Android phone.
2. Open it. If Android asks, allow your browser or file manager to **install unknown apps**.
3. If Google Play Protect shows a warning, tap **More details → Install anyway**. ERP Customer is
   distributed outside the Play Store, so Google hasn't reviewed it.

Requires Android 7.0 or newer.

## Note

The backend runs on a free hosting tier and sleeps when idle. If the app loads slowly the first
time, give it about a minute to wake up.
